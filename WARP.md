# WARP.md — orielsy.com

## Repository Links for Project & Research Entries

When authoring or editing Project and Research entries on orielsy.com:

- Each **Project** entry must point to its **actual project repository** when one exists. Never substitute a general GitHub profile link in place of a per-project repo.
- Each **Research** entry may include a GitHub link **only** when there is a genuine companion repo, experiment, or reference implementation. If no specific repository exists for that entry, **omit the `github` field entirely**.
- Do **not** use the general GitHub profile as a placeholder for per-entry repository links.
- The general GitHub profile belongs **only** in global site navigation, footer, and About surfaces — never as a Project or Research entry's repository link.

If a Project or Research entry has no real repo to link to, leave the repo field absent rather than fabricating or substituting the profile link.
