Project Overview

speechBubbles is an on-device desktop overlay and live-broadcast graphics platform designed to bring television-style dynamic graphics and automated speech transcription to streamers, presenters, and video creators without relying on cloud APIs.

The system is structured as two decoupled tiers:

  1. The Desktop Overlay Client (speechBubbles): An Electron and Vue 3 application that generates frameless, transparent, hardware-accelerated broadcast graphics—including animated speaker lower-thirds, title banners, topic tickers, and speech bubble captions. Broadcasters capture these windows directly in OBS Studio (or similar streaming software) using chroma-key or alpha transparency masks.
  2. The Local Audio & Inference Engine (whisper-api): A local Python FastAPI service that ingests real-time 16 kHz 16-bit PCM audio streams over WebSockets (ws://localhost:8000/listen), performs Voice Activity Detection (VAD) to trim silence, and runs local Whisper neural transcription models on machine silicon.

Core System Highlights

1. OBS-Optimized Broadcast Graphics Engine

Television news broadcasts frequently display context when a speaker is introduced—credentials, affiliation, topic titles, and disclaimers.

speechBubbles translates this workflow into a dedicated operator console:

  • Lower-Third Banners (BannerView.vue): Configurable dual-tone gradient banners with entrance and exit timing queues.
  • Presenter Nametags (TitleView.vue): Dropdown title badges for displaying speaker names and professional roles.
  • Chroma-Key & Alpha Ingestion: Windows are formatted with distinct background borders and transparent viewport layers, allowing streaming software to isolate graphics with zero edge bleed.

2. High-Throughput 16 kHz Audio Streamer

Browser audio interfaces typically record at 44.1 kHz or 48 kHz stereo. Feeding uncompressed raw audio directly to neural models creates unnecessary bandwidth and computation overhead.

In CaptionControl.vue, the client utilizes the Web Audio API to downsample audio in real time:

  • The raw AudioContext buffer is downsampled to a 16 kHz mono float stream.
  • Audio samples are converted to signed 16-bit PCM integers (convertFloat32ToInt16) and streamed as binary blobs over WebSockets with minimal garbage collection churn.

3. Asynchronous Non-Blocking Whisper Inference

Running heavy neural models on an asynchronous web framework like FastAPI can easily block the event loop, causing dropped WebSocket heartbeats and audio buffer overflow.

The backend engine offloads neural computation:

  • Incoming PCM chunks are accumulated into a sliding scratch buffer.
  • When sufficient audio is buffered, model.transcribe() executes inside a dedicated worker thread via asyncio.to_thread(), keeping the main event loop free to ingest continuous audio packets.
  • Segments are checked against silence and temperature probability thresholds to eliminate ghost hallucinations during natural speaking pauses.

4. Dynamic Bounding-Box Layout & Animation

When new transcription segments arrive from the backend, CaptionsView.vue computes the physical layout of active bubbles on screen:

  • Using getBoundingClientRect(), each caption calculates its offset relative to previous elements.
  • Bubble pop-in animations and vertical shifts are orchestrated using double-buffered requestAnimationFrame transitions.

Technical Stack

  • Desktop Shell: Electron with electron-acrylic-window transparency and qhotkeys system bindings.
  • Frontend Layer: Vue 3 (Composition API / <script setup>), Pinia state management, and Vite.
  • Audio Capture: Web Audio API (AudioContext, createScriptProcessor / MediaStreamAudioSourceNode).
  • Inference Engine: Python 3.10+, FastAPI, Uvicorn, OpenAI Whisper, WhisperX, and PyAnnote Audio.
  • Video Production: OBS Studio window capture with hardware-accelerated GPU layers.
