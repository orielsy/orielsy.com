The Adaptive Enterprise UI Lab is a long-lived reference application rather than a one-off article demo. Its first phase accompanies the [Documentation-Driven Adaptive UX](/research/documentation-driven-adaptive-ux) research and demonstrates how authored product knowledge, validation, version context, user familiarity, and response policy can alter an interface without using an LLM. Future phases are intended to explore non-chat AI capabilities and adaptive inference runtimes within the same application.

## Phase 1 · Implemented

Phase 1 currently demonstrates deterministic product knowledge, state-aware guidance, validation, product/runtime context, knowledge applicability, response policy, and adaptive UI behavior around a focused Data Connection scenario.

It intentionally does **not** use LLMs, semantic retrieval, embeddings, WebLLM, MCP, or remote AI APIs.

## Future Phases · Planned, Not Implemented

A later Phase 2 may explore non-chat AI capabilities such as intent interpretation, semantic product-knowledge retrieval, contextual explanation adaptation, structured extraction, and inline transformations.

A later Phase 3 may explore adaptive inference execution across browser-local, machine-local, server, edge, or cloud runtimes.

Those phases are roadmap directions only. They should not be described as implemented until source exists.
