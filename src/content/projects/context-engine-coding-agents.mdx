## System Overview

The Context Engine operates as a local background daemon adhering to Anthropic's **Model Context Protocol (MCP)** specification. When a coding agent (e.g., Warp, Claude Code, Cursor) attaches to the repository, the engine establishes an IPC connection and exposes domain-specific tools.

```text
+---------------------+        MCP JSON-RPC        +------------------------+
| Coding Agent Client | <------------------------> | Repository MCP Daemon  |
| (Warp / Agent CLI)  |                            +------------------------+
+---------------------+                                        |
                                         +---------------------+---------------------+
                                         |                                           |
                                         v                                           v
                              +--------------------+                      +--------------------+
                              | AST Prop Analyzer  |                      | Architecture ADR   |
                              | & Type Extractor   |                      | Semantic Index     |
                              +--------------------+                      +--------------------+
```

## Key Capabilities

### 1. Granular Interface Inspection
Instead of forcing an agent to read entire 1,000-line component implementation files, the engine provides `get_component_interface`, which returns only:
- Exported TypeScript interfaces and prop types.
- Allowed design system variant tokens.
- Bound state machine events.

### 2. Architectural Boundary Guarding
Before proposing code edits, the agent queries `validate_architectural_invariants` to verify:
- No illegal cross-boundary package imports.
- Compliance with the repository's data-fetching paradigm.
- Proper use of error boundary wrappers.

## Technical Stack

- **Protocol Runtime**: TypeScript with `@modelcontextprotocol/sdk`.
- **Parsing Engine**: Babel / TypeScript compiler API AST extractors.
- **Local Cache**: SQLite with vector embeddings for semantic document search.
