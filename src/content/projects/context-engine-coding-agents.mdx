## Proposed System Overview

The proposed Context Engine would operate as a local background daemon adhering to Anthropic's **Model Context Protocol (MCP)** specification. When a coding agent (e.g., Warp, Claude Code, Cursor) attaches to the repository, the service could establish an IPC connection and expose domain-specific tools.

```text
+---------------------+        MCP JSON-RPC        +------------------------+
| Coding Agent Client | <------------------------> | Repository MCP Daemon  |
| (Warp / Agent CLI)  |                            +------------------------+
+---------------------+                                        |
                                         +---------------------+---------------------+
                                         |                                           |
                                         v                                           v
                              +--------------------+                      +--------------------+
                              | AST Prop Analyzer  |                      | Architecture ADR   |
                              | & Type Extractor   |                      | Semantic Index     |
                              +--------------------+                      +--------------------+
```

---

## Key Capabilities

### 1. Granular Interface Inspection
Instead of forcing an agent to read entire component implementation files, the proposed service could provide `get_component_interface`, returning only:
- Exported TypeScript interfaces and prop types.
- Allowed interface variant tokens.
- Bound state machine events.

### 2. Architectural Boundary Guarding
Before proposing code edits, an agent could query `validate_architectural_invariants` to check:
- No illegal cross-boundary package imports.
- Compliance with the repository's data-fetching paradigm.
- Proper use of error boundary wrappers.

## Proposed Technical Direction

- **Protocol Runtime**: TypeScript with `@modelcontextprotocol/sdk`.
- **Parsing Approach**: Babel / TypeScript compiler API AST extraction.
- **Potential Local Cache**: SQLite with vector embeddings for semantic document search.
